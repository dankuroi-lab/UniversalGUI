# UniversalGUI

Uma biblioteca GUI universal para Roblox Executors, similar à Fluent, mas totalmente funcional e compatível.

## 🚀 Funcionalidades

- ✅ Janelas arrastáveis
- ✅ Múltiplos temas (Dark, Light, Neon, Amethyst)
- ✅ Botões, Sliders, Toggles, Labels
- ✅ Botão flutuante
- ✅ Sistema de presets
- ✅ Totalmente personalizável
- ✅ Compatível com todos os executores

## 📦 Instalação

```lua
-- Carregar a biblioteca
local UniversalGUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/[SEU-USER]/UniversalGUI/main/lib/Core.lua"))()
